# 🌌 Vault Galaxy

**Obsidian Vault Visualizer** – An interactive 3D visualization of your Obsidian vault files rendered as a galaxy of planets and connection lines.

---

## Description

Vault Galaxy transforms your Obsidian vault structure into an immersive 3D galaxy:

- **Planet Graph**: Each Markdown file is represented as a glowing planet, connected by lines where wikilinks exist
- **Tag Stars**: Tags appear as colorful stars linked to their associated files
- **Interactive Markdown Viewer**: Clickable wikilinks on the right open the Markdown content with full syntax highlighting
- **Neon Cyberpunk Design**: Neon colors, glow effects, and animated connection lines

---

## Usage Guide

### Opening a Vault

1. Click the **"Open Vault Directory"** button on the starting screen
2. Select the folder of your Obsidian vault in the file dialog
3. The galaxy will then be generated and displayed automatically

### Navigation in the Galaxy

| Action | Control |
|---|---|
| **Rotate** | Left mouse button + drag |
| **Pan** | Right mouse button + drag |
| **Zoom** | Mouse wheel |
| **Reset View** | **"⟐ Reset View"** button top-left |

### Exploring Files

1. **Click a planet** → The planet is focused, centered and Markdown content will be displayed in the right-side viewer
2. **Click a tag star** → Shows all files with that tag in the right-side viewer

When clicking on a planet or tag all connections to other planets and tags and the connections get highlighted for better visualization and navigation.

### Wikilinks in the Markdown Viewer

| Format | Function |
|---|---|
| `[[Page]]` | Opens the file |
| `[[Page\|Display Name]]` | Opens the file with a named link |
| `[[#Headline]]` | Scrolls to the headline in the current document |
| `[[Page#Headline]]` | Opens the file and scrolls to the headline |
| `#Tag` | Filters files by this tag |

> **Note**: Tables with wikilinks are automatically detected. The escape character `\|` in tables is correctly interpreted as a pipe.

### Supported Markdown Syntax

The viewer supports:

- **Bold**, *Italic*, ~~Strikethrough~~
- Headings (H1–H6)
- Lists (ordered & unordered)
- Blockquotes
- Code blocks
- Tables
- YAML frontmatter (removed during rendering)
- Obsidian callouts (`> [!note]`, `> [!tip]`, etc.)
- Embeds (`![[image.png]]`)
- LaTeX Math (`$$...$$`)

## Technical Details

- **Single-File App**: Everything in one HTML file – no installation, no build process
- **Libraries**: Three.js (3D rendering), Marked.js (Markdown parsing)
- **Browser**: Modern browsers with WebGL support (Chrome, Firefox, Edge)
